# Pré-Cadastro de Pedidos (Bancodoc)

Protótipo navegável da tela **Gestão de Pré-Cadastro de Pedidos**, no padrão do design system NovoBancodoc.

## Stack

- HTML / CSS / JavaScript puro
- jQuery + Select2 + jQuery UI (assets reais do sistema)
- Dados mockados em `localStorage` via `nb-mock.js`

## Desenvolvimento local

```bash
npm start
```

Abra [http://localhost:3000](http://localhost:3000).

Ou abra `index.html` diretamente no navegador (`file://`).

## Deploy

Projeto estático na Vercel: https://precadastrocsn.vercel.app/
## Perfis de teste

- **Demarco** — consulta sob demanda (Filtrar)
- **Cliente** — visão restrita ao Grupo CSN, com classificação de pedidos em Pendência Contratual
